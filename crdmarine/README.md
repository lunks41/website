# CRD Marine S A LLC

Modern Next.js website for CRD Marine — boat and barge services from Port of Fujairah.

## Stack

- Next.js (App Router)
- TypeScript
- Brand colours: black + green (logo)

## Develop

```bash
cd D:\Proj\Work\all-projects\website\crdmarine
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — home
- `/services` — fresh water, goods, crew transport
- `/fleet` — all vessels + Q88 PDFs
- `/fleet/[slug]` — vessel particulars
- `/about` — company
- `/contact` — Fujairah operations desk
