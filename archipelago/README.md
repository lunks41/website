# Archipelago Middle East Shipping

Modern Next.js marketing site for Archipelago Middle East Shipping LLC.

```bash
npm install
npm run build
npm start
```

- Site: https://archipelago.ae
- Ops email: operations@archipelago.ae
- WhatsApp: +971 50 433 3783

## IIS deploy

Copy to server (e.g. `D:\Proj\websites\archipelago`):

- `.next\`
- `node_modules\`
- `public\`
- `logs\`
- `package.json`
- `package-lock.json`
- `next.config.ts`
- `web.config`
